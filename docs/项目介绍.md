# 爽哥刷金币助手

**版本 V1.0.2.3 ｜ 更新日期 2026-10-23 ｜ 出品：杨爽工作室**

挂在电脑上的安卓自动化小工具：通过 adb 模拟手指，帮你在抖音 / 快手 / 视频号等 App 里**自动刷视频、自动赚金币、自动关广告**，支持多台手机同时跑，各自独立节奏。

> 分工原理：**scrcpy 只负责把手机画面投到电脑给你看**，所有滑动与点击走 **adb**。两者互不干扰——关掉投屏窗口也不影响自动化继续跑。

---

## 一、它能干什么

| 能力 | 说明 |
| --- | --- |
| 自动刷短视频 | 抖音 / 快手 / 抖音极速版 / 快手极速版 / 微信视频号通用，随机间隔上滑，模拟真人节奏 |
| 多设备同刷 | 一台电脑带多台手机，勾选哪几台刷哪几台，每台独立线程、独立间隔、独立计数 |
| 自动签到 | 点一下「立即签到」，自动唤醒手机 → 打开 App → 点签到按钮 → 处理广告 |
| 定时点宝箱 | 每 N 分钟（默认 30，可调 5~240）自动点一次宝箱 |
| 图像任务 | 截图比对找按钮，**按钮真出现了才点**——比固定坐标靠谱得多 |
| 广告自动关闭 | 匹配到 × 关闭按钮就点掉；匹配不到交给「误触自动恢复」兜底 |
| 界面异常自动纠正 | 定期截屏判断画面，遇到广告 / 弹窗 / 跑错 App / 回到桌面，自动按返回或重启 App |

| 自动检查更新 / 启动公告 | 打开就知道有没有新版、有没有新通知 |

## 二、安装与准备

### 1. 装软件

两种方式任选：

- **安装包**：双击 `爽哥刷金币助手_V1.0.2.3_Setup.exe`，按提示装完即可（已内嵌 adb 与 scrcpy，`bin\` 目录一并带上）
- **免安装**：直接用 `dist\ShuageCoinHelper\` 里的 `爽哥刷金币助手.exe`，双击即用，**不需要装 Python**

如果你想用语音控制，另有一个可选安装包 `爽哥刷金币助手_语音模型_V1.0.2.3_Setup.exe`（约 40MB 的中文离线模型）。不装它也能正常刷，只是语音控制不可用。

### 2. 准备手机

1. 手机打开「开发者选项」→ 打开「USB 调试」
2. USB 线连电脑，手机弹出的「允许 USB 调试」点允许
3. **手机要解锁**（有锁屏密码的，工具滑不动）

无线连接（不想插线）：

1. 手机与电脑连**同一个 WiFi**
2. 手机开发者选项里打开「无线调试」，查看 IP 地址
3. 工具里填 `IP:5555` → 点「连接」

### 3. 准备投屏（可选）

想看手机画面，需要 `scrcpy`。工具安装包已带 `bin\` 目录；如用免安装版，把 `scrcpy.exe` 放进 `bin\` 或确保它在系统 PATH 里。找不到时点「打开投屏」会弹提示，不影响自动化本身。

## 三、快速上手（3 步）

1. **连接**：双击 exe → 点「检测设备」（无线设备先填 `IP:5555` 点「连接」）→ 设备出现在列表里并勾选
2. **开 App**：手机打开抖音或快手，停在刷视频的界面
3. **开刷**：点「▶ 开始刷」→ 3 秒后手机开始自己滑

停止：点「■ 全部停止」。防息屏开启时会自动还原你原来的息屏设置。

> **目标应用 = 你点「开始刷」那一刻手机前台的那个 App**。中途被广告或别的 App 顶走，工具会识别并自动拉回来，期间不刷也不计数。

## 四、界面怎么用

界面自上而下：设备区 → 四个标签页 → 控制区 → 状态栏 → 日志区。**设备区、控制区、状态栏、日志区始终常驻**，只有中间的功能区收进标签页，所以窗口再小也不会把常用按钮压没。窗口默认不超过 860×940，最小 800×760，可自由拖拽，组件随宽度自适应。

### 设备区（最上方）

| 元素 | 作用 |
| --- | --- |
| 检测设备 | 刷新在线设备列表（列表可滚动，支持鼠标滚轮） |
| 打开投屏 | 为勾选的设备各开一个 scrcpy 窗口 |
| 无线连接 | 填 `IP:5555` 连接无线设备 |
| ✎ 备注 | 给这台设备起个名（如「小号1」），**按序列号保存，重启后仍在**；显示为 `备注名（serial）` |
| ⏸ 暂停 | 只暂停**这一台**（需在设置里开启该按钮）；其它设备照常刷 |

### 标签页一：刷视频

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 自动上滑刷视频 | 勾选 | 不勾选 = **纯任务模式**：不滑动不计数，只每 10 秒巡检宝箱 / 图像任务 / 防息屏 |
| 最小 / 最大间隔 | 3 / 10 秒 | 每个视频停留时间在此区间随机，**最低保护线 1 秒** |
| 下滑回看概率 | 10% | 随机往下滑回看上一个，更像真人 |
| 自动打开投屏 | 开 | 点开始刷时自动为每台设备拉起 `scrcpy -s <序列号>` |
| 误触弹窗自动恢复 | 开 | 离开目标应用时：按返回两次 → 重启目标 App |

### 标签页二：赚金币任务

- **防息屏**（默认开）：刷的期间把息屏时间临时调至 30 分钟 + 每 10 分钟唤醒一次；停止后自动还原
- **✍ 采集坐标**：弹出手机截图，选择「保存为签到坐标」后在图上点一下签到按钮位置
- **🔔 立即签到**：一键自动签到（首次使用须先采集坐标）
- **🎁 定时点宝箱**：勾选后按设定间隔点宝箱坐标（须先采集坐标）

### 标签页三：图像任务（推荐主力用法）

解决「按钮**到时间才出现**」这类任务——固定坐标点早了是白点，图像识别则等它真出现才点。

**采集模板**：点「🖼 采集图像模板」→ 在手机截图上**按住拖拽框选那个按钮** → 起名保存。五种类型：

| 类型 | 行为 |
| --- | --- |
| 任务按钮 | 画面里出现就点（如「开」状态的宝箱按钮） |
| 广告关闭按钮 × | 广告的关闭图标，标记为**通用**，所有广告场景都拿它匹配 |
| 等待元素出现 | 两步采集：①框选「判断区域」②指定出现后动作——**点击另一个位置**或**按返回键** |
| 等待元素消失 | 元素还在就等着并记住位置；**一消失立刻点它原来的位置**（专治「X 秒后可开」倒计时） |
| 直播间 | 误入直播间时命中 → **自动按返回退出**，优先级最高，先于广告/任务处理 |

**模板管理**：

- 存放于 `templates\<分类目录>\模板名_时间戳.png`，分类目录可自定义（如「宝箱专用」），也可随时「✏ 改分类」搬家
- 「✏ 编辑模板」可改：名称、应用包名、类型、**识别阈值**（0.50~0.98，每个模板独立，默认 0.80）、分类目录、**点击偏移**（按模板宽高百分比微调点击位置）、出现后动作、备注，还能**更换图片**
- 「＋ 新增模板(选图片)」可直接用本地图片建模板，不必手机截图
- 「📂 打开模板目录」直接打开文件夹，方便备份 / 手工整理

**运行逻辑**：每 15 秒（可调）截屏搜索一次，条件满足自动执行，命中后冷却 60 秒。没配任何模板时自动退化为只看前台应用，原有误触恢复不受影响。

> **技巧一**：只框选按钮「可开状态」的样式（显示「开」字那种），倒计时未到时样式不同匹配不上，天然实现「到时间才点」。
> **技巧二**：「等待消失」（倒计时文字）+「等待出现」（可开按钮）组合使用，双保险。

## 五、语音控制怎么用

语音控制默认关闭，勾选后程序在**本机离线**监听麦克风，全程不联网。

**防误触是两次唤醒**，流程如下：

1. **待唤醒**：正常识别中，此时说什么都不执行
2. 说第一次「**小金币**」→ 进入半唤醒，状态栏提示「已听到唤醒词，请再说一次」，并语音回你「再说一次」
3. 再说一次「**小金币**」→ 正式唤醒，状态栏「已唤醒，请说指令」，语音回「我在」
4. 说「**开始**」/「开刷」/「开始刷」→ 开始刷；说「**停止**」/「停」/「全部停止」→ 全部停止
5. 执行后自动退回待唤醒；半唤醒后 10 秒没第二次唤醒会退回，唤醒后 12 秒没命令也会退回

细节：

- 唤醒词为**模糊包含**匹配，句子里包含就算命中
- **清空唤醒词 = 语音控制不可用**，状态栏会提示「未设置唤醒词，语音控制不响应命令」
- 语音命令走的是和界面按钮完全相同的逻辑，设备勾选、单台暂停规则一致
- 中文模型 `vosk-model-small-cn-0.22` 需放在程序目录或 `models\` 子目录；缺失时开启会提示并自动回退，**不影响其它任何功能**

## 六、配置与数据文件

所有数据集中在程序目录的 `爽哥刷金币助手配置.json`，按不同键分存，互不干扰：

| 键 | 存什么 |
| --- | --- |
| `scrcpy` / `adb` | 程序路径 |
| `ui` | 所有勾选项与参数（下次打开自动恢复上次状态） |
| `sign` / `box` | 签到与宝箱坐标 |
| `templates` | 图像模板记录（图片本身在 `templates\` 下） |

几个放心设计：

- **启动自愈**：没有 `templates\` 自动建，没有配置文件自动生成默认配置，配置损坏也会重建，不用手工收拾
- **旧文件自动迁移**：老版本 `爽哥刷金币助手坐标.json`、`刷视频工具配置.json`、更早的「爽哥快手抖音任务自动助手*.json」会自动合并/复制进新配置，**旧文件原样保留做备份，不删不覆盖**
- **坐标按百分比存**：分辨率相近的手机通用
- ⚠️ 配置文件与 `templates\` **必须和 exe 放一起**，删了要重新配置/采集

日志：底部日志区实时显示，格式 `[2026-10-08 14:30:05] [INFO] ...`，分 INFO / WARNING / ERROR，出错会附异常摘要（文件 + 行号 + 原因）。日志区最多留最近 800 行。点「日志」开独立窗口可滚动回看（可关自动跟随），点「导出日志」导出到 `logs\爽哥刷金币助手_时间戳.log`（UTF-8 带 BOM，记事本直接看）。

## 七、常见问题

| 问题 | 解决 |
| --- | --- |
| 检测不到设备 | 无线：确认同一 WiFi + 已开无线调试，填 `IP:5555` 点连接；USB：确认已允许 USB 调试 |
| 滑动没反应 | 手机没解锁（有密码要先手动解锁）；或看日志是否提示「被弹窗挡住」 |
| 日志显示「恢复中」 | 手机被弹窗或别的 App 挡住，工具正在自动拉回来，稍等 |
| 签到点偏了 | App 改版挪了按钮，重新采集坐标 |
| 图像任务从不命中 | 模板框得太小或样式选错，重新框选**完整按钮**；或降低该模板的识别阈值 |
| 一直报界面异常后停止 | 连续纠正 3 次仍无法恢复会主动停该台设备（防死循环），状态显示「界面异常」，手动回到 App 后重新开始 |
| 语音控制不响应 | 日志确认是否提示「未设置唤醒词」或「模型未找到」；确认内存 ≥4GB、CPU ≥4 核 |
| 手机发热 | 间隔别低于 3 秒；长时间挂机发热属正常 |
| 多台一起跑电脑卡 | scrcpy 投屏占 CPU，关掉不看的投屏窗口即可，自动化本身几乎不占资源 |

## 八、注意事项（请务必看）

1. **高频点赞 / 关注类任务未提供，也不建议自动化**——这是平台风控重点，可能被限流甚至封号
2. 间隔最低 1 秒是保护线，正常建议 3~10 秒，越接近真人越安全
3. App 大版本更新后按钮位置可能变化，重新采集坐标 / 模板即可
4. 本工具通过 adb 模拟操作，使用风险自担，请遵守各平台用户协议
5. 防息屏会修改你手机的息屏时间，停止时会自动还原；异常退出（如强杀进程）后请手动检查一下
