# 爽哥刷金币助手 使用说明

> 基于 scrcpy 投屏 + adb（系统 PATH 自动识别，可在设置页自定义路径）实现的安卓自动刷视频 + 赚金币任务工具
> 操作人：杨爽 ｜ 当前版本：**V1.0.2.3** ｜ 更新日期：2026-10-23

---

## 一、这是什么

一个挂在电脑上的小工具，通过 adb 模拟手指操作手机：

- **自动刷短视频**（抖音 / 快手 / 视频号 / 极速版通用）
- **多台手机同时刷**，各自独立节奏
- **赚金币任务**：自动签到、定时点宝箱、图像识别到点自动点
- **广告自动关闭**：点完任务自动等倒计时、找 × 关闭、回不到就重启 App

**分工原理**：scrcpy 只负责投屏画面给你看，滑动/点击操作走 adb（系统 PATH 的 adb，可在设置页自定义），两者互不干扰。

---

## 二、文件说明

| 文件                       | 作用                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------- |
| `爽哥刷金币助手.exe`       | 主程序，**双击即用**，无需安装 Python                                                         |
| `爽哥刷金币助手配置.json`  | **统一配置与坐标数据**：scrcpy/adb 路径、界面勾选项与参数（远程地址已内置代码）+ 签到/宝箱坐标与图像模板记录（启动时若发现旧版 `爽哥刷金币助手坐标.json` 会自动合并迁移后删除旧文件） |
| `templates\` 文件夹        | 图像识别的按钮模板图片，**按应用分子目录**存放（自动生成、自动归档）                          |
| `vosk-model-small-cn-0.22\` 文件夹 | **语音控制（离线识别）专用中文模型**，需手动放入程序目录（或 `models\` 子目录）；仅开启语音控制时使用，缺失只提示不影响其他功能 |
| `赞助名单模板.md`          | 赞助名单文件的格式模板（内容见 4.9）；改完传到 `https://sgzs.xn--yrv04v.com/sponsors.md` 即可 |
| `website\` 文件夹          | 官网静态页（`index.html` 单文件 + `assets\` 图标），与软件运行无关，可单独部署                |

> ⚠️ 配置文件（含坐标与模板数据）和 `templates\` 要和 exe 放在一起，删了就得重新配置/采集。
> 🛠 **启动自愈（无需手动创建）**：程序启动时若没有 `templates\` 目录会自动创建；若没有 `爽哥刷金币助手配置.json` 会自动生成默认配置（含 `scrcpy`/`adb`/`ui`/`notice_seen` 键及空的 `sign`/`box`/`templates` 键）；配置文件损坏或为空时也会自动重建为合法默认配置，不需要手工建目录/写配置。
> 📁 **配置与坐标统一存放**：scrcpy/adb 路径、界面勾选项、签到/宝箱坐标与图像模板记录都保存在同一个 `爽哥刷金币助手配置.json` 里（不同数据分键存放，互不混淆）。
> 🔄 **旧文件自动迁移**：启动时若发现旧版 `爽哥刷金币助手坐标.json`，会自动把其中的坐标/模板数据**合并迁移**进 `爽哥刷金币助手配置.json`，校验成功后才删除旧文件；更早版本的 `刷视频工具配置.json` / `刷视频工具坐标.json`（或更早的「爽哥快手抖音任务自动助手*.json」）同样会自动把内容**复制**成新名字的文件并写一条日志；**旧文件原样保留**当备份，不会删除、不会覆盖你现有数据。
> 🗂 **模板按应用分目录**：每个 App 的模板各放各的子目录，文件名带模板名，一眼看得懂，方便备份和手工整理：

```
爽哥刷金币助手.exe
templates\
  ├─ 快手极速版\
  │    ├─ 去观看_1790118436115.png
  │    └─ 去看广告_1790118559850.png
  ├─ 快手\
  ├─ 抖音\
  ├─ 抖音极速版\
  ├─ 微信视频号\
  └─ 通用\          ← 广告关闭 × 等跨应用通用模板
```

> 目录名由采集时手机前台的应用自动决定；旧版本散在 `templates\` 根目录的模板（文件名 `tpl_时间戳.png`），**首次启动会自动归档**到对应应用子目录，并把文件名自动改成「模板名_时间戳.png」，无需手动整理。

## 三、快速上手（3 步）

1. **连接手机**：USB 插电脑，或手机与电脑同一 WiFi 后开启无线调试
2. 双击 `爽哥刷金币助手.exe` → 点「**检测设备**」（无线设备填 `IP:5555` 点「连接」）
3. 手机打开抖音/快手 → 点「**▶ 开始刷**」→ 3 秒后开始自动刷

停止：点「■ 全部停止」。防息屏开启时会自动还原你原来的息屏设置。

### 界面布局一览

界面自上而下分区，常用区**始终可见**，其余功能收进标签页，不会被压扁或跑出窗口：

| 区域          | 位置           | 说明                                                                                       |
| ------------- | -------------- | ------------------------------------------------------------------------------------------ |
| 📱 **设备区** | 最上方常驻     | 检测设备 / 打开投屏 / 无线连接；设备列表**可滚动**（设备再多也不会撑破窗口），支持鼠标滚轮 |
| 🗂 **标签页** | 中部           | ①「刷视频」②「赚金币任务」③「图像任务」④「设置」，点标签切换                               |
| 🎮 **控制区** | 标签页下方常驻 | ▶ 开始刷 / ■ 全部停止 / 检查更新 / 📢 公告 / ❤ 赞助 / 关于 / 总计计数                      |
| 📊 **状态栏** | 控制区下方常驻 | 显示当前状态（运行中、下次滑动倒计时、看广告中…）                                          |
| 📜 **日志区** | 最下方常驻     | 自动占满剩余空间并带滚动条，**窗口拉大日志跟着变大**                                       |

> 窗口尺寸按你的屏幕自动计算（默认不超过 860×940），最小 800×760，可自由拖拽缩放，所有组件按窗口宽度自适应。

## 四、功能详解

### 4.1 刷视频参数

| 参数             | 默认    | 说明                                                                      |
| ---------------- | ------- | ------------------------------------------------------------------------- |
| 自动上滑刷视频   | 勾选    | 不勾选 = **纯任务模式**：不滑动不计数，只每 10 秒巡检宝箱/图像任务/防息屏 |
| 最小/最大间隔    | 3~10 秒 | 每个视频停留时间在此区间随机，**最低限 1 秒**保护手机                     |
| 下滑回看概率     | 10%     | 随机往下滑回看上一个，更像真人                                            |
| 自动打开投屏     | 开      | 点开始刷时自动拉起 scrcpy 投屏（每台已选设备拉起对应 `scrcpy -s <序列号>`；scrcpy 未安装时提示配置） |
| 误触弹窗自动恢复 | 开      | 离开目标应用时：按返回 ×2 → 重启目标 App                                  |

> 目标应用 = 点「开始刷」那一刻手机前台的应用。检测到弹窗/跳转别的 App 时**不刷不计数**，恢复后继续。

**界面异常自动纠正（默认开启）**：刷视频过程中除了按「前台应用」判断，还会**定期截屏做画面级判断**（默认每 5 秒检查一次），确认当前画面是否正常刷视频界面；判定为异常时按画面类型自动分层纠正，全程写日志（INFO/WARNING/ERROR）：

| 画面类型         | 判定依据（复用图像任务模板）                 | 纠正动作                                       |
| ---------------- | -------------------------------------------- | ---------------------------------------------- |
| 广告/弹窗        | 匹配到 `close` 关闭按钮模板                  | 点击关闭按钮位置；失败/无按钮 → 按返回键       |
| 弹窗（未消失）   | `wait_disappear` 模板仍出现在画面            | 按返回键                                       |
| 错误/未知画面    | 模板均未命中判定为异常的画面                 | 按返回键重试                                   |
| 已退出/回到桌面  | 前台为桌面/启动器（如 com.miui.home）        | 自动用 monkey 重新拉起目标 App                 |
| 跳转其他 App     | 前台为其他应用（广告落地页等）               | 自动用 monkey 重新拉起目标 App                 |

- 连续纠正 **3 次**仍无法恢复：**自动停止该台设备**（状态标签显示"界面异常"），并语音播报「**{设备标识} 界面异常无法恢复**」（语音提醒总开关需开启），避免死循环空转；恢复正常后自动继续刷并清空失败计数
- 开关在「设置」页：**界面异常自动纠正**，勾选/取消即时生效并保存；老版本配置升级后默认开启
- 每台设备独立检查与计数，只影响异常的那台，其他设备不受影响
- 未配置任何图像模板时自动退化为仅按前台应用判断（原有误触恢复能力不受影响）

### 4.2 多设备同刷

- 「检测设备」列出所有在线手机，**勾选哪几台刷哪几台**
- 每台手机独立线程、独立随机间隔、独立计数，右上角显示总计
- USB / 无线混连都可以
- **单台暂停/继续（默认关闭）**：设置页勾选「设备行显示单台暂停/继续按钮」后，每台设备行尾部会出现「⏸ 暂停」小按钮，只控制**该台**设备：点暂停后该台线程原地阻塞（不刷不计数，状态标签显示"已暂停"），其他设备照常刷；再点「▶ 继续」恢复。全局「■ 全部停止」仍一键全停所有设备，不受单台暂停影响
- **设备备注（默认无备注）**：每台设备行 serial 旁有「✎ 备注」小按钮，点击弹出输入框为该设备设置备注名（如"小号1"）；设置后设备行显示 `备注名（serial）`，方便区分多台手机。备注按设备序列号（serial）保存，**重新检测/重启后仍保留**；输入留空并保存即可清除备注；未设置备注的设备只显示 serial
- **语音提醒（默认关闭）**：设置页勾选「语音提醒（设备上下线/异常播报）」后，用电脑语音统一按「**设备标识 + 状态**」播报（设备标识优先备注名，无备注用 serial；IP 形式如 `192.168.9.20:5555` 播报时自动截取 IP 部分）：
  - 设备上线：「{标识} 已连接」；设备从检测列表消失：「{标识} 已断开」
  - 设备变 offline：「{标识} 设备离线」；unauthorized 或手动连接失败：「{标识} 连接异常」
  - 单台刷视频 adb 命令**连续失败 5 次**：「{标识} 刷视频异常」
  - 同一设备只播报一次，拔掉再插回 / 恢复正常后才重新播报，避免反复打扰；关闭开关即全部静默
  - 使用 Windows 自带语音合成（SAPI），无需额外下载模型；若电脑缺少语音组件会自动跳过播报，不影响其他功能

### 4.3 赚金币任务

#### ☀️ 防息屏（默认开）

刷视频期间把手机息屏时间临时调到 30 分钟 + 每 10 分钟唤醒一次，保证计时类金币任务不断档；停止后**自动还原**原设置。

#### 🔔 自动签到（需先采集坐标）

1. 手机打开快手/抖音极速版的签到页面（签到按钮可见）
2. 工具点「✍ 采集坐标」→ 弹出手机截图 → 选「保存为签到坐标」→ **点击图中签到按钮位置**
3. 以后点「🔔 立即签到」：自动唤醒手机 → 启动 App → 点签到按钮 → 自动处理广告

#### 🎁 定时点宝箱（需先采集坐标）

勾选后，刷视频过程中每隔 N 分钟（默认 30，可调 5~240）自动点一次宝箱坐标。

### 4.4 图像任务（推荐，比固定坐标更聪明）

解决「按钮**到时间才出现/才能点**」的任务：

1. 点「🖼 采集图像模板」→ 截图上**按住拖拽框选按钮** → 起名保存
2. 五种模板类型：
   - **任务按钮**：到点自动点（如宝箱可开状态的按钮）
   - **广告关闭按钮 ×**：广告弹窗的关闭图标，标记为**通用**，所有广告场景都拿来匹配
   - **等待元素出现**（两步采集）：
     ① 框选「判断区域」——元素出现在这里就算触发
     ② 再指定出现后的动作：**点击图中另一个位置**（如关闭 ×）**或点「✋出现后按返回键」**
   - **等待元素消失**：元素还在 → 持续等待并记住位置；**一消失 → 自动点击原位置**（适合「X秒后可开」倒计时——倒计时消失即时间到）
   - **直播间**（V1.0.2.1 新增）：刷视频误入直播间时，把直播画面框选为模板保存为「直播间」类型；运行时命中 → **自动按返回键退出直播间**并继续正常刷视频（只退出、不点击、不等待消失，命中优先级最高，先于广告/任务处理）
3. 运行时每 15 秒（可调）截屏搜索，条件满足自动执行；命中后 60 秒冷却
4. **模板存放与查看**：模板保存进 `templates\<分类目录>\模板名_时间戳.png`，**分类目录可自定义**——采集窗口里「保存到分类目录」默认按当前应用名，可下拉选已有分类或直接输入新名字（如「宝箱专用」）；也可以在图像任务页选中模板点「✏ 改分类」随时挪动；下拉框按「分类 · 模板名」分组显示，点「📂 打开模板目录」可直接打开文件夹查看/备份/手工整理
5. **模板可编辑**（V1.0.2.0 起）：图像任务页选中模板点「✏ 编辑模板」→ 可修改**模板名称、应用包名、模板类型、识别阈值（0.50~0.98，每模板可单独调，缺省用全局 0.80）、分类目录、点击偏移（相对模板宽高的百分比，可微调点击位置，0,0=模板中心）、「等待元素出现」的出现后动作、备注**，还能**更换图片**（从本地选新图自动替换，程序生成的旧图自动清理）；点「＋ 新增模板(选图片)」→ 直接选一张本地图片即可创建新模板，无需手机截图。所有改动实时保存进 `爽哥刷金币助手配置.json`（坐标/模板数据存于其中的 sign/box/templates 键），旧版配置完全兼容（缺省字段不写入）

> 💡 技巧：框选「可开状态」的按钮样式（如显示"开"字时），倒计时没到时样式不同匹配不到，**天然实现到时间才点**。
> 💡 等待出现+等待消失可组合使用：倒计时文字设「等待消失」+ 可开按钮设「等待出现」，双保险自动点。

### 4.5 广告关闭（V1.0.1.1 起统一走图像任务）

> 旧版「赚金币任务」页的「点击后自动看广告并关闭 + 广告时长」勾选已**删除**（与图像任务功能重复）。

现在广告关闭完全由**图像任务**处理：

1. 广告弹窗出现时，截屏匹配你采集的「**广告关闭按钮 ×**」模板（通用，所有应用都匹配）
2. 匹配到 → 自动点击 × 关闭广告
3. 没匹配到 → 不动作，交给**误触自动恢复**兜底（按返回 + 重启目标 App）
- **关闭按钮模板库越攒越全**：遇到新广告的 × 样式，在图像任务里采集一次（类型选「广告关闭按钮×」），以后全自动
- 想等广告倒计时结束再关？给倒计时文字采一个「等待元素消失」模板即可组合使用

### 4.6 设置（路径设置）

界面下方「设置」区可自定义，**换电脑时用**：

1. 点「浏览」选择 scrcpy.exe（投屏程序，未配置时默认走系统 PATH 里的 scrcpy）
2. 点「浏览」选择 adb.exe（命令工具，未配置时默认走系统 PATH 里的 adb）
3. 点「保存设置」，写入 `爽哥刷金币助手配置.json`，下次启动自动生效

> **scrcpy 开源地址**：设置区最下方有一行蓝色链接「scrcpy 开源地址：github.com/Genymobile/scrcpy（点击打开）」，点一下会用默认浏览器打开 scrcpy 的 GitHub 开源主页（scrcpy 由 Romain VIMONT 开发、Genymobile 开源维护，本项目使用其作为投屏组件）。

> 自动打开投屏 / 打开投屏按钮通过 `scrcpy -s <设备序列号>` 拉起投屏窗口，每台设备独立窗口；若 scrcpy 未安装（PATH 与配置路径均找不到）会弹窗提示去设置页配置路径，不会卡死。
> 老版本配置里的 `qtscrcpy` 路径会自动迁移为 `scrcpy` 键（仅当同目录存在 scrcpy.exe 时迁移，否则置空走 PATH）。

> **更新 / 公告 / 赞助地址已内置固定地址**（代码常量，配置文件中不再提供）。默认值如下，如需更换需修改源码常量后重新打包：

| 功能     | 内置固定地址                                    | 作用       |
| -------- | ----------------------------------------------- | ---------- |
| 更新地址 | `https://sgzs.xn--yrv04v.com/update.txt`        | 检查更新   |
| 公告地址 | `https://sgzs.xn--yrv04v.com/notice.txt`        | 启动公告   |
| 赞助二维码 | `https://zz.xn--yrv04v.com/weixin.png`        | 赞助二维码 |
| 赞助名单 | `https://sgzs.xn--yrv04v.com/sponsors.md`       | 赞助名单   |

> `update.txt` 内容格式（首行「版本号」或「版本号|下载链接」）：
>
> - `V1.0.2.3` （仅版本号）
> - `V1.0.2.3|https://下载链接` （版本号 + 下载链接）
>
> 填的不是 http/https 链接（比如随手打的字）也会自动跳过，不会报错。
>
> 💡 **内容写法宽松**（V1.0.0.9 起）：不要求「版本号|链接」固定格式，只要**第一行里能找到版本号（如 V1.0.2.3）**，程序自动识别，例如写 `最新版本 V1.0.2.3 下载 https://xxx` 一样有效；识别不到版本号会在日志提示。

> 路径未配置时默认走系统 PATH 中的 scrcpy / adb，首次使用建议先确认已安装（scrcpy 官网或 `pip install scrcpy-client` 配套环境）。
> 路径写错时点「打开投屏」会弹窗提示重新选择，不会卡死。
> **检查更新**：更新地址已内置固定（见 4.6 表），启动时后台静默检查 + 控制区「检查更新」手动查；发现新版本会弹窗询问是否打开下载链接。版本号四段式比较（V1.0.0.9 < V1.0.1.0）。

### 4.7 启动公告（远程文本）

想把「最新动态」通知到每台电脑上？把公告写成一个**纯文本文件**放到网上（自己的服务器 / GitHub / Gitee / NAS 都行），程序启动时自动读取并弹窗展示。**实现方式和检查更新完全一样**，都是读一个远程文本链接。

**地址已内置固定**（`https://sgzs.xn--yrv04v.com/notice.txt`），工作室把文件传上去就能对所有电脑生效，无需在配置里填地址。如需更换地址，需修改源码常量（`APP_NOTICE_URL`）后重新打包。

自己写公告内容时：

1. 用记事本新建文本文件，写下公告内容（支持多行、中文），例如：

   ```
   【公告】爽哥刷金币助手 V1.0.1.8
   1. 远程地址迁移到新域名
   2. 无需配置，开箱即用
   ```

2. 把文件传到网上或内网 NAS，拿到直链（如 `https://xxx.com/notice.txt`），将地址替换到代码常量后重新打包

3. 上传后下次启动自动读取（不用重启电脑，重新打开程序即可）

**行为说明**：

| 情况                           | 表现                                                    |
| ------------------------------ | ------------------------------------------------------- |
| 公告内容**有变化**             | 启动时弹出「📢 公告」窗口（内容长可滚动），日志同步记录 |
| 公告内容和上次一样             | **不弹窗**（避免每次开机都打扰），日志显示"公告无变化"  |
| 地址打不开 / 404 / 内容为空    | 只写日志，**不影响刷视频等任何功能**                    |
| 想随时看公告                   | 点控制区「**📢 公告**」按钮，立即重新读取并展示         |

> 💡 换行兼容：记事本保存的换行会自动转成标准换行，长公告显示时不会出现双倍空行。
> 💡 公告文件用 UTF-8 编码保存（记事本默认即可），中文不会乱码。

### 4.8 界面状态记忆（自动，无需操作）

所有**勾选项和参数**（刷视频间隔、下滑概率、上滑开关、防息屏、定时宝箱及间隔、图像任务及间隔、自动投屏、误触恢复等）都会自动保存到配置文件：

- **保存时机**：点「▶ 开始刷」时 + 点「保存设置」时 + 关闭窗口时
- **恢复时机**：下次打开工具自动恢复上次的勾选状态
- **存储位置**：统一配置文件 `爽哥刷金币助手配置.json` 的 `ui` 键（坐标/模板数据在同一文件的其他键下，互不混淆）
- **首次启动自动创建**：程序目录下还没有 `爽哥刷金币助手配置.json` 或 `templates\` 目录时，启动会自动创建目录并生成默认配置（含 `scrcpy`/`adb`/`ui`/`notice_seen` 键及空的 `sign`/`box`/`templates` 键）；配置文件损坏或为空时同样会自动重建为默认配置，无需手动处理；老版本配置里的 `qtscrcpy` 键会自动迁移为 `scrcpy`（同目录存在 scrcpy.exe 才迁移，否则置空）

### 4.10 语音控制（开刷/停止，默认关闭）

> 📢 **语音提醒（设备上下线/异常播报，默认关闭）**：与语音控制相互独立。勾选设置页「语音提醒（设备上下线/异常播报）」后，设备上线播报（有备注「备注名称上线」、无备注「新设备上线」）、下线「已断开」、offline「设备离线」、连接失败/unauthorized「连接异常」、单台刷视频连续失败 5 次「刷视频异常」；下线/异常按「设备标识 + 状态」播报（详见 4.2）。默认关闭；使用 Windows 自带 SAPI 语音合成，无需额外模型。

设置页勾选「语音控制（开刷/停止，离线识别）」后，程序会**本地离线**监听麦克风语音，识别到命令词自动开始刷 / 全部停止，无需操作鼠标。

- **默认关闭**：勾选后才启动监听，关闭开关或退出程序自动停止监听
- **配置要求**：内存 **≥ 4GB** 且 CPU **≥ 4 核**（逻辑核心），不满足时设置页的语音控制开关自动置灰不可用；该判断基于本机实时配置，无需额外设置
- **离线识别方案**：内置 vosk + sounddevice（已打包进 exe），识别全程在本机完成，不联网
- **命令词**（代码内置，方便后续调整）：**「开始刷」「开刷」「开始」** → 开始刷；**「停止」「停」「全部停止」** → 全部停止；连续识别 3 秒内只触发一次，避免误重复
- **唤醒词（默认「小金币」，可自定义）**：为防止误触发，默认采用**两次唤醒**流程——① **待唤醒**：持续识别，第一次听到唤醒词（如「小金币」）进入**半唤醒**状态（状态栏显示「已听到唤醒词，请再说一次」，并语音播报「再说一次」），此时**还不会**执行命令；② **半唤醒**：**第二次**听到唤醒词才正式进入**唤醒态**（状态栏显示「已唤醒，请说指令」，并语音播报「我在」）；③ **唤醒态**：此时说命令词才会执行（开始刷 / 全部停止），执行后自动退回待唤醒；半唤醒后 **10 秒**内没说第二次唤醒词会自动退回待唤醒；唤醒态 **12 秒**内没听到有效命令也会自动退回待唤醒
  - 唤醒词可在设置页「唤醒词（语音控制）」文本框修改（如改为「小助手」「嗨助手」等），修改即时保存，重启后仍生效；老配置未设置过唤醒词时自动使用默认「小金币」
  - 唤醒词匹配为**模糊包含**：识别文本里包含唤醒词即算一次命中，不要求整句完全一致；多字唤醒词（如「小金币小金币」）同样按包含匹配
  - 半唤醒状态中听到的**非唤醒词不会打断**等待（只会在说第二次唤醒词或超时后退出）；**未唤醒（待唤醒/半唤醒）状态下识别到任何命令词一律不执行**，只有唤醒态中命令词才会被响应
  - **唤醒态中再次听到唤醒词**：保持唤醒并**重置命令窗口**（再给 12 秒），不会退出唤醒、也不会误执行命令
  - **清空唤醒词**＝语音控制**不可用**：此时**不响应任何命令**（状态栏提示「未设置唤醒词，语音控制不响应命令」），需在设置中填写唤醒词后才能使用语音控制
  - 唤醒功能仅在「语音控制」开关开启时生效，与「语音提醒」互不影响
- **中文模型需外置**：把 `vosk-model-small-cn-0.22` 文件夹放到程序目录（或程序目录下 `models\` 子目录）；未放模型时开启开关会弹提示并自动回退，**不影响其他任何功能**
- 模型下载地址：https://alphacephei.com/vosk/models （选 `vosk-model-small-cn-0.22`，解压后文件夹名保持原名）
- 提示：语音命令走的是和界面按钮相同的 start()/stop()，设备勾选状态、单台暂停等规则完全一致

### 4.11 日志与排查（查看 / 导出）

程序底部常驻**日志区**，实时显示运行状态；日志统一带**级别 + 时间戳**格式，方便定位问题：

- **日志格式**：`[2026-10-08 14:30:05] [INFO] 设备已连接`，级别分 **INFO / WARNING / ERROR** 三种
- **异常自动带堆栈**：出错时（如设备连接失败、刷视频中断、语音监听异常）日志会额外附上**异常摘要**（出错位置所在代码文件与行号 + 错误原因），不用再贴一大段原始报错
- **日志上限**：界面日志区最多保留最近 **800 行**，超出自动裁剪最早的日志，避免界面卡顿

**查看日志窗口**：主界面控制区点「**日志**」按钮，打开独立日志窗口：

- 只读展示当前全部日志，可滚动查看、可拉大窗口
- **实时跟随**：默认自动滚动到底部（有新日志自动跟随）；取消勾选「自动滚动」后可自由滚动回看
- 窗口关闭后自动停止刷新，不占用资源

**导出日志**：日志窗口点「**导出日志**」按钮（或主界面控制区「导出日志」按钮），一键导出当前全部日志：

- **默认导出位置**：程序目录 `logs\` 文件夹，文件名带时间戳，如 `logs\爽哥刷金币助手_20261008_143005.log`
- **编码**：UTF-8 带 BOM（记事本直接打开中文不乱码）
- 导出成功会提示保存路径；导出失败（如磁盘不可写）会弹出错误提示，**不影响程序继续运行**

**排查提示**：设备连不上先看日志是否提示「连接失败/设备离线」；刷视频不动先看是否提示「被弹窗挡住」或「恢复中」；语音控制不响应先确认日志里是否提示「未设置唤醒词」或「模型未找到」。

## 五、常见问题

| 问题             | 解决                                                                           |
| ---------------- | ------------------------------------------------------------------------------ |
| 检测不到设备     | 无线：确认同一网络 + 已开无线调试，填 `IP:5555` 点连接；USB：手机允许 USB 调试 |

| 手机发热         | 间隔别低于 3 秒；长时间挂机属正常现象                                          |

## 六、注意事项

1. ⚠️ 高频**点赞/关注**类任务未提供且不建议自动化，平台风控重点，可能限流封号
2. 间隔最低 1 秒是保护线，正常建议 3~10 秒
3. 多台手机同时投屏时 scrcpy 占 CPU 稍高，属投屏开销，工具本身几乎不占资源
4. App 大版本更新后按钮可能变化，重新采集坐标/模板即可
5. 坐标按屏幕**百分比**存储，分辨率相近的手机可通用
